# Final Submission Checklist — JFLM

Use this checklist immediately before clicking "Submit" on the Elsevier Editorial Manager portal.

## A. Manuscript file (single PDF or DOCX)

- [ ] Tam metin İngilizceye çevrildi (profesyonel veya doğrulanmış)
- [ ] Title page'de yazar(lar), kurum, ORCID, sorumlu yazar e-posta var
- [ ] Structured abstract ≤250 kelime (Background/Methods/Results/Conclusion)
- [ ] 4–6 anahtar kelime (MeSH-uyumlu)
- [ ] Başlık "Single-Expert" ifadesini içeriyor
- [ ] §2.12 framing notu (03_framing_note) entegre edildi
- [ ] Limitations bölümünde single-expert sınırı net beyan
- [ ] Section 10.1 prospektif validasyon planı görünür
- [ ] Vancouver-numbered referans formatı (Elsevier basic style)
- [ ] AI/LLM kullanım beyanı Methods + Acknowledgements'ta
- [ ] Etik onay/exemption ifadesi (IRB karar no eklenmeli)
- [ ] Conflict of interest beyanı: None
- [ ] Funding beyanı: None
- [ ] Ana metin kelime sayısı 6,000–8,000 arası (JFLM tipik aralık)

## B. Figures (separate high-res files)

- [ ] **Figure 1** — PRISMA-style flow diagram (300 dpi TIFF veya vector PDF)
- [ ] Figure caption(s) ana dosya sonunda ayrı sayfada

## C. Supplementary materials (separate ZIP veya ayrı dosyalar)

- [ ] **Supplementary Table S1** — Confusion matrix
- [ ] **Supplementary Table S2** — Per-class metrics
- [ ] **Supplementary Table S3** — Reliability coefficients (κ + weighted κ + Krippendorff α)
- [ ] **Supplementary Section S2** — Sample size justification (Sim & Wright 2005)
- [ ] **Supplementary Section S3** — Disagreement analysis (n=6)
- [ ] **TRIPOD checklist** (04_TRIPOD_checklist) — 22/22 işaretlenmiş
- [ ] **STROBE checklist** (05_STROBE_checklist) — 22/22 işaretlenmiş
- [ ] Reproducibility scripts ZIP veya GitHub link (anonim, double-blind review için)

## D. Cover letter (separate file)

- [ ] 01_cover_letter_EN.md → DOCX/PDF
- [ ] Sorumlu yazar imzası ve tarih
- [ ] "Not under consideration elsewhere" beyanı
- [ ] Gerekirse 2–3 önerilen hakem (suggested reviewers) — alan dışından

## E. Editorial Manager metadata

- [ ] Article type: **Original Article** (NOT Review, NOT Case Report)
- [ ] Section: **Forensic Medicine / Medico-legal**
- [ ] Yazar sırası, e-posta, ORCID doğrulandı
- [ ] Sorumlu yazar = Nurcan Denli Bayır
- [ ] Suggested reviewers (3 önerilir, çıkar çatışması olmayan) — opsiyonel ama kabul olasılığını artırır
- [ ] Excluded reviewers (varsa) — opsiyonel
- [ ] Cover letter uploaded
- [ ] Manuscript uploaded
- [ ] Figure(s) uploaded
- [ ] Supplementary uploaded
- [ ] Author agreement form imzalandı
- [ ] CRediT taxonomy beyanı (yazar katkıları)

## F. Son okuma

- [ ] Tüm tablolarda numara doğru
- [ ] Tüm referanslar metinde atıfı var ve listede mevcut
- [ ] DOI/PMID'ler tıklanır halde
- [ ] Türkçe karakter bozukluğu yok
- [ ] Decimal ayırıcı tutarlı (İngilizce: nokta)

## G. Submit sonrası

- [ ] Submission ID notlandı
- [ ] Tahmini ilk karar: 2–4 ay
- [ ] Status takip planı: 4 hafta sonra ilk kontrol; 8 hafta sonra status sorgu hakkı
