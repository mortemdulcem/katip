## Packages
framer-motion | Smooth animations for page transitions and interactions
react-markdown | Rendering markdown content from AI analysis
date-fns | Formatting dates for paper metadata and notes
clsx | Utility for constructing className strings conditionally
tailwind-merge | Utility for merging Tailwind CSS classes

## Notes
- Tailwind config must include custom fonts: 'Outfit' (display) and 'DM Sans' (body)
- Auth is handled via Replit Auth (useAuth hook)
- API endpoints are defined in @shared/routes
- Dark mode support required via Tailwind's 'dark' class
